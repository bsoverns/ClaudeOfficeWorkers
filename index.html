How Claude connects

Claude Code hooks run claude_hook.py, which tells this office what each session is doing: a new prompt sends a worker to the boss for a work slip, tool calls keep them busy, a failed tool sends them to the help desk, and when Claude stops or needs permission they wait in the mailroom.

Saying done, thanks or task complete to Claude (or pressing Done ✓) sends the worker back to the break room. Closing the session does too.

Test from a command prompt:

py office.py start "Build the login page"
py office.py trouble
py office.py wait
py office.py done
py office.py demo
